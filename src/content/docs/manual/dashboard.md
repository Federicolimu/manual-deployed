# Dashboard

El Dashboard es el panel principal del sistema donde puedes ver un resumen de todas las actividades y métricas importantes.

## Descripción General

Al ingresar al sistema, el Dashboard te presenta:

- **Resumen de actividades recientes**
- **Métricas clave del sistema**
- **Accesos rápidos a las funciones principales**
- **Notificaciones importantes**

## Secciones del Dashboard

### Métricas Principales

Visualiza estadísticas importantes como:
- Total de candidatos activos
- Prospectos en proceso
- Tareas pendientes
- Proyectos activos

### Actividad Reciente

Lista de las últimas acciones realizadas en el sistema.

### Accesos Rápidos

Botones de acceso directo a las funciones más utilizadas.

:::tip[Consejo]
Personaliza tu Dashboard para mostrar la información más relevante para tu rol.
:::
