# Projects

La sección de Projects te permite gestionar los proyectos y vacantes disponibles en la organización.

## Vista de Proyectos

### Listado de Proyectos

Cada proyecto muestra:
- Nombre del proyecto
- Cliente asociado
- Número de vacantes
- Candidatos asignados
- Estado del proyecto

### Crear Nuevo Proyecto

1. Haz clic en "Nuevo Proyecto"
2. Completa la información:
   - Nombre del proyecto
   - Descripción
   - Cliente
   - Requisitos
   - Número de vacantes
   - Fecha límite
3. Guarda el proyecto

## Gestión de Proyectos

### Asignar Candidatos

1. Abre el proyecto
2. Haz clic en "Asignar Candidatos"
3. Selecciona candidatos de la lista
4. Confirma la asignación

### Seguimiento

Monitorea el progreso del proyecto:
- Candidatos en proceso
- Entrevistas programadas
- Posiciones cubiertas

### Estados del Proyecto

- **Activo**: Proyecto en proceso de selección
- **Pausado**: Temporalmente detenido
- **Completado**: Vacantes cubiertas
- **Cancelado**: Proyecto cancelado

:::tip[Consejo]
Revisa regularmente el estado de tus proyectos para cumplir con los tiempos establecidos.
:::
