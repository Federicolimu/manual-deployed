# My Pending Tasks

Esta sección te permite gestionar y dar seguimiento a todas las tareas que tienes asignadas.

## Vista de Tareas Pendientes

### Listado de Tareas

Visualiza todas tus tareas pendientes organizadas por:
- **Prioridad** (Alta, Media, Baja)
- **Fecha de vencimiento**
- **Proyecto asociado**
- **Candidato relacionado**

### Filtros Disponibles

Puedes filtrar tus tareas por:
- Estado
- Prioridad
- Fecha
- Proyecto

## Acciones Disponibles

- **Marcar como completada**: Una vez terminada la tarea
- **Editar tarea**: Modificar detalles de la tarea
- **Reasignar**: Transferir la tarea a otro usuario
- **Agregar notas**: Documentar avances o comentarios

:::caution[Importante]
Las tareas con fecha de vencimiento próxima se mostrarán destacadas para tu atención.
:::
