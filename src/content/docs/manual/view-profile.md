# View Profile

La sección View Profile te permite ver y editar la información de tu perfil de usuario.

## Información del Perfil

### Datos Personales

- Nombre completo
- Correo electrónico
- Teléfono
- Cargo/Rol
- Departamento

### Foto de Perfil

Actualiza tu foto de perfil:

1. Haz clic en la imagen de perfil
2. Selecciona una nueva imagen
3. Ajusta el recorte si es necesario
4. Guarda los cambios

## Editar Perfil

### Actualizar Información

1. Haz clic en "Editar Perfil"
2. Modifica los campos necesarios
3. Guarda los cambios

### Cambiar Contraseña

1. Ve a "Seguridad"
2. Ingresa tu contraseña actual
3. Ingresa la nueva contraseña
4. Confirma la nueva contraseña
5. Guarda los cambios

## Preferencias

- Idioma preferido
- Notificaciones
- Zona horaria
- Tema (claro/oscuro)

:::note[Nota]
Algunos campos pueden estar bloqueados y solo pueden ser modificados por un administrador.
:::
