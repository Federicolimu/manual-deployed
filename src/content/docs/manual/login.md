# Login

Bienvenido a la guía de acceso al sistema ATS BETTERWAY DEVS.

## Acceso al Sistema

Para ingresar al sistema, sigue estos pasos:

1. **Navega a la página de inicio de sesión**
2. **Ingresa tus credenciales**
   - Usuario o correo electrónico
   - Contraseña
3. **Haz clic en el botón "Iniciar Sesión"**

## Recuperación de Contraseña

Si olvidaste tu contraseña:

1. Haz clic en "¿Olvidaste tu contraseña?"
2. Ingresa tu correo electrónico registrado
3. Revisa tu bandeja de entrada
4. Sigue el enlace para restablecer tu contraseña

:::tip[Consejo]
Mantén tus credenciales seguras y no las compartas con terceros.
:::

:::note[Nota]
El sistema cerrará tu sesión automáticamente después de un período de inactividad.
:::
