El módulo de Projects centraliza la gestión de todas las posiciones de talento activas y cerradas dentro del ATS. Cada Project representa una iniciativa de reclutamiento asociada a una empresa y posición.

## Uso dentro del ATS

Projects se utiliza para crear, organizar y dar seguimiento a las búsquedas de talento. Desde cada Project se administran los candidatos y prospectos asociados, así como su avance dentro del proceso de reclutamiento.

El estado de un Project determina si una búsqueda está activa, en pausa o cerrada, lo que impacta directamente en la operación del equipo de reclutamiento.

### New Project

Permite crear una nueva vacante o búsqueda de talento dentro del ATS. Cada Project representa una necesidad específica de un cliente o una iniciativa de reclutamiento activa.

Un Project define:
- Qué perfil se está buscando
- Para qué cliente
- Desde qué pools de talento se alimenta
- Qué flujos de comunicación y evaluación se utilizarán

Es el punto de partida para que prospectos y candidatos puedan ser asociados a una búsqueda concreta.

La vista de Projects muestra en tiempo real todas las posiciones creadas dentro del ATS. Estas se organizan en tres grupos principales:

- **All:** Contiene todas las posiciones que han existido históricamente.
- **Active:** Incluye únicamente las vacantes que se encuentran abiertas y en proceso de reclutamiento.
- **Closed:** Contiene las vacantes que ya fueron cerradas, ya sea porque se cubrió la posición o porque el cliente decidió finalizar la búsqueda.

### Detalles de la Tabla

- **Company:** Nombre del cliente para el cual se está reclutando.
- **Name:** Nombre de la posición o búsqueda activa.
- **Prospects:** Cantidad y acceso a las personas identificadas como posible talento que aún se encuentran en evaluación.
- **Candidates:** Cantidad y acceso a las personas ya validadas y listas para participar en un proceso de selección.
- **Location:** Ubicación asociada a la vacante.
- **Status:** Estado operativo del Project (activo o cerrado).
- **Visibility:** Indica si la vacante está visible dentro de los flujos activos del ATS.
- **Projects Status:** Indicadores que reflejan si la configuración del Project está completa o si existen elementos pendientes.
- **Created Date:** Fecha en la que se creó el Project.
- **Actions:** Permite acceder al Project, editarlo o eliminarlo.
